# Full-Stack CRUD Application

A full-stack CRUD application built with **Vue.js**, **PHP**, and **TypeScript**.

## 📋 Overview

App CRUD is a modern, feature-rich application for managing data with Create, Read, Update, and Delete operations. It combines a responsive Vue.js frontend with a robust PHP backend.

## 🛠 Tech Stack

- **Frontend**: Vue 3 (54.3%)
- **Backend**: PHP (30.6%)
- **Type Safety**: TypeScript (11.4%)
- **Styling**: CSS (1.5%)
- **Templating**: Blade (0.7%)
- **JavaScript**: (1.5%)

## ✨ Features

- Full CRUD functionality
- Responsive user interface
- Type-safe frontend development with TypeScript
- RESTful API backend
- Modern Vue 3 components

## 🚀 Getting Started

### Prerequisites
- Node.js
- PHP 7.4+
- MySQL/SQLite

### Installation

```bash
# Clone the repository
git clone https://github.com/eosrmg/app-CRUD.git
cd app-CRUD

# Install frontend dependencies
npm install

# Install backend dependencies
composer install

# Configure environment
cp .env.example .env

# Run migrations
php artisan migrate
